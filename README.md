# 动画素材说明

## 当前需要的图片文件：

### 闲置动画（Idle Animation）
将以下图片放入此文件夹：

1. `cat_idle.png` - 闲置状态（当前使用的小猫图片）
2. `cat_idle_1.png` - 闲置动画第1帧（可选）
3. `cat_idle_2.png` - 闲置动画第2帧（可选）

## 使用说明：

### 方案 A：单帧模式（当前）
- 只需要 `cat_idle.png` 一张图片
- 程序会循环显示同一张图片（模拟动画）

### 方案 B：多帧动画（推荐）
如果你有多帧动画素材：
1. 将不同帧命名为 `cat_idle_0.png`, `cat_idle_1.png`, `cat_idle_2.png`
2. 修改代码中的加载逻辑即可

## 素材制作建议：

- **格式**：PNG（支持透明背景）
- **尺寸**：建议 128x128 到 256x256 像素
- **背景**：必须是透明背景
- **帧数**：2-4 帧即可实现流畅的呼吸或眨眼动画

## 示例动画效果：

- 帧1：小猫睁眼
- 帧2：小猫半闭眼
- 帧3：小猫闭眼
- 循环播放 → 形成眨眼效果
