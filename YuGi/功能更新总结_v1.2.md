# YuGi 桌面宠物 - 功能更新总结 v1.2

## ✅ 已完成的功能

### 1. ⚙️ 可调整帧率和移动速度

#### 实现内容
- ✅ 新增配置项：`InitialMoveDuration`、`RandomMoveDurationMin`、`RandomMoveDurationMax`
- ✅ 创建图形化设置界面（WPF 窗口）
- ✅ 使用 Slider 控件调整参数
- ✅ 实时显示当前值
- ✅ 保存配置到 JSON 文件
- ✅ 动画帧率修改后立即生效

#### 可调整的参数
| 参数 | 范围 | 默认值 |
|------|------|--------|
| 动画帧率 | 50-200ms | 100ms (10 FPS) |
| 初始移动时间 | 5-60秒 | 18秒 |
| 随机移动最小时间 | 1-10秒 | 1秒 |
| 随机移动最大时间 | 1-10秒 | 3秒 |

#### 访问方式
- 右键菜单 → 设置
- 托盘菜单 → 设置

---

### 2. 🖥️ 点击显示后台运行程序

#### 实现内容
- ✅ 使用 `Process.GetProcesses()` 获取系统进程
- ✅ 过滤只显示有窗口标题的程序
- ✅ 显示程序名称、窗口标题、内存占用
- ✅ 限制显示前 20 个程序
- ✅ 异常处理（某些进程可能无法访问）

#### 显示信息
```
🖥️ 当前运行的程序：

📌 程序名称
   窗口: 窗口标题
   内存: XX MB
```

#### 访问方式
- 左键点击宠物
- 右键菜单 → 查看运行程序

## 🎯 用户使用流程

### 流程一：调整设置
```
右键点击宠物
    ↓
选择"设置"
    ↓
调整参数（拖动滑块）
    ↓
点击"保存"
    ↓
设置生效
```

### 流程二：查看运行程序
```
左键点击宠物
    ↓
弹出程序列表窗口
    ↓
查看程序信息
    ↓
点击"确定"关闭
```

### 流程三：拖动宠物
```
右键点击宠物
    ↓
选择"拖动宠物"
    ↓
停止自动移动
    ↓
按住左键拖动
```
