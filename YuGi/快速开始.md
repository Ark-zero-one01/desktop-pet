# YuGi 桌面宠物 - 快速开始指南

## 🚀 快速启动

### 方法一：使用启动脚本（推荐）
双击 `run.bat` 文件即可自动编译并运行程序。

### 方法二：使用命令行
```bash
cd DesktopPet
dotnet run
```

### 方法三：直接运行编译后的程序
```bash
cd DesktopPet\bin\Debug\net8.0-windows
DesktopPet.exe
```

### 🎬 启动效果
程序启动后：
1. **宠物出现** - 在屏幕左下角登场
2. **匀速移动** - 向右匀速移动（可调整速度）
3. **循环出现** - 从右边离开后从左边重新出现
4. **持续循环** - 无限循环移动

## 📋 系统要求

- **操作系统**: Windows 10/11
- **运行时**: .NET 8.0 Runtime 或 SDK
- **下载地址**: https://dotnet.microsoft.com/download/dotnet/8.0

## 🎮 使用说明

### 基本操作
| 操作 | 说明 |
|------|------|
| **左键点击** | 显示后台运行的程序列表 |
| **右键点击** | 显示快捷菜单 |
| **托盘图标** | 左键切换显示/隐藏，右键打开完整菜单 |

### 右键菜单功能
- **拖动宠物**: 停止移动并准备拖动
- **查看运行程序**: 显示后台程序列表
- **设置**: 打开设置界面，调整帧率和移动速度
- **隐藏宠物**: 隐藏窗口
- **退出**: 退出程序

### 功能特性
✅ **14帧流畅动画** - YuGi角色闲置动画  
✅ **匀速循环移动** - 从左到右匀速移动，循环出现  
✅ **可调节速度** - 通过设置界面调整移动速度  
✅ **系统托盘** - 最小化到托盘，不占用任务栏  
✅ **窗口置顶** - 始终显示在其他窗口之上  
✅ **后台程序监控** - 点击查看运行中的程序  

## ⚙️ 配置说明

配置文件位置：`%AppData%\DesktopPet\config.json`

```json
{
  "WindowLeft": 1720.0,        // 窗口X坐标
  "WindowTop": 880.0,          // 窗口Y坐标
  "AnimationSpeed": 100,       // 动画速度（毫秒/帧）
  "AutoMove": true,            // 是否自动移动
  "MoveIntervalMin": 3,        // 移动间隔最小值（秒）
  "MoveIntervalMax": 7         // 移动间隔最大值（秒）
}
```

### 调整动画速度
- **更快**: 将 `AnimationSpeed` 改为 `80`（12.5 FPS）
- **更慢**: 将 `AnimationSpeed` 改为 `120`（8.3 FPS）
- **默认**: `100`（10 FPS）

### 禁用自动移动
将 `AutoMove` 改为 `false`，或在托盘菜单中取消勾选"自动移动"。

## 🎨 自定义角色

### 更换序列帧图片
1. 准备14张透明PNG图片（建议尺寸：200x200像素）
2. 命名为 `01.png` 到 `14.png`
3. 放入 `Assets/YuGi_Idle/` 文件夹
4. 重新运行程序

### 修改帧数
如果你的动画不是14帧，需要修改代码：

打开 `MainWindow.xaml.cs`，找到：
```csharp
idleFrames = new BitmapImage[14]; // 改为你的帧数
```

## 🐛 常见问题

### Q: 程序启动后看不到宠物？
A: 检查系统托盘（任务栏右下角），左键点击托盘图标显示宠物。

### Q: 提示缺少 .NET 运行时？
A: 下载安装 .NET 8.0 Runtime：https://dotnet.microsoft.com/download/dotnet/8.0

### Q: 宠物移动到屏幕外了？
A: 删除配置文件 `%AppData%\DesktopPet\config.json`，重新启动程序。

### Q: 如何完全退出程序？
A: 右键点击宠物或托盘图标，选择"退出"。

### Q: 动画播放不流畅？
A: 在配置文件中调整 `AnimationSpeed` 值，或检查CPU占用情况。
