# YuGi 桌面宠物 - 新功能说明 v1.3

## 🎉 版本 1.3 新增功能

### 🔄 匀速循环移动

宠物现在会匀速向右移动，从右边离开屏幕后自动从左边重新出现，形成无限循环！

## 🎯 功能特点

### 1. 匀速移动
- ✅ **匀速运动**: 不再使用缓动函数，实现真正的匀速移动
- ✅ **持续时间可调**: 通过设置界面调整移动速度（5-60秒）
- ✅ **流畅动画**: 配合序列帧动画，呈现自然的行走效果

### 2. 循环出现
- ✅ **无缝循环**: 从右边离开后立即从左边重新出现
- ✅ **自动重复**: 无需手动操作，自动循环移动
- ✅ **可控制**: 通过配置文件的 AutoMove 控制是否循环

### 3. 简化交互
- ✅ **移除随机移动**: 不再随机跳跃，专注于向右移动
- ✅ **移除自动移动开关**: 托盘菜单更简洁
- ✅ **保留拖动功能**: 仍可通过右键菜单拖动宠物

## 📝 使用说明

### 启动效果
```
程序启动
    ↓
宠物出现在屏幕左下角
    ↓
匀速向右移动
    ↓
从右边离开屏幕
    ↓
从左边重新出现
    ↓
继续向右移动（循环）
```

### 调整移动速度
1. 右键点击宠物
2. 选择"设置"
3. 调整"初始移动时间"滑块
4. 点击"保存"

**速度参考**：
- 5秒：非常快
- 18秒：默认速度（推荐）
- 30秒：较慢
- 60秒：非常慢


## 🔧 技术实现

### 匀速移动
```csharp
DoubleAnimation moveX = new DoubleAnimation
{
    From = this.Left,
    To = targetX,
    Duration = duration,
    EasingFunction = null // 不使用缓动函数，实现匀速移动
};
```

### 循环逻辑
```csharp
moveX.Completed += (s, e) => 
{ 
    // 将宠物移动到屏幕左侧外面
    this.Left = -this.Width - 50;
    
    // 继续向右移动
    if (config.AutoMove)
    {
        StartContinuousRightMovement();
    }
};
```

## 📊 与之前版本的对比

| 特性 | v1.2 | v1.3 |

| 移动范围 | 屏幕内随机位置 | 从左到右 |

## ⚙️ 配置说明

### 配置文件
位置：`%AppData%\DesktopPet\config.json`

```json
{
  "WindowLeft": 10.0,
  "WindowTop": 880.0,
  "AnimationSpeed": 100,
  "AutoMove": true,              // 控制是否循环移动
  "InitialMoveDuration": 18      // 移动持续时间（秒）
}
```

### 停止循环移动
如果想停止循环移动，可以：
1. 编辑配置文件，将 `AutoMove` 改为 `false`
2. 重启程序
