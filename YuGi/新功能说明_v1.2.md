# YuGi 桌面宠物 - 新功能说明 v1.2

## 🎉 版本 1.2 新增功能

### 1. ⚙️ 可调整帧率和移动速度

现在可以通过设置界面自定义各种参数！

#### 可调整的参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| **动画帧率** | 50-200ms | 100ms (10 FPS) | 控制序列帧动画的播放速度 |
| **初始移动时间** | 5-60秒 | 18秒 | 启动时从左到右移动的持续时间 |
| **随机移动最小时间** | 1-10秒 | 1秒 | 每次随机移动的最短时间 |
| **随机移动最大时间** | 1-10秒 | 3秒 | 每次随机移动的最长时间 |

#### 如何打开设置

**方法一：右键菜单**
1. 右键点击宠物
2. 选择"设置"

**方法二：托盘菜单**
1. 右键点击系统托盘图标
2. 选择"设置"

设置会自动保存到：`%AppData%\DesktopPet\config.json`

```json

  "WindowLeft": 10.0,
  "WindowTop": 880.0,
  "AnimationSpeed": 100,
  "AutoMove": true,
  "MoveIntervalMin": 3,
  "MoveIntervalMax": 7,
  "InitialMoveDuration": 18,
  "RandomMoveDurationMin": 1,
  "RandomMoveDurationMax": 3

```

### 2. 🖥️ 点击显示后台运行程序

左键点击宠物即可查看当前系统中正在运行的程序！

#### 功能特点

- ✅ **实时显示**: 显示当前所有有窗口的运行程序
- ✅ **详细信息**: 显示程序名称、窗口标题、内存占用
- ✅ **智能过滤**: 只显示有窗口标题的程序（过滤后台服务）
- ✅ **限制数量**: 显示前20个程序，避免列表过长

#### 显示内容示例

```

📌 chrome
   窗口: Google Chrome
   内存: 256 MB

📌 Code
   窗口: Visual Studio Code
   内存: 512 MB

📌 explorer
   窗口: 文件资源管理器
   内存: 128 MB

📌 WeChat
   窗口: 微信
   内存: 320 MB

...
```

#### 使用方法

**左键点击宠物** → 自动弹出程序列表窗口

#### 其他查看方式

也可以通过右键菜单访问：
1. 右键点击宠物
2. 选择"查看运行程序"

## 📝 使用场景

### 场景一：调整动画速度
如果觉得动画太快或太慢：
1. 右键 → 设置
2. 调整"动画帧率"滑块
3. 保存

### 场景二：调整移动速度
如果觉得宠物移动太快或太慢：
1. 右键 → 设置
2. 调整"初始移动时间"和"随机移动时间"
3. 保存

### 场景三：查看系统资源
想知道哪些程序在运行：
1. 左键点击宠物
2. 查看程序列表和内存占用

### 场景四：拖动宠物
想移动宠物到其他位置：
1. 右键 → 拖动宠物
2. 按住左键拖动到目标位置

## 🔧 技术实现

### 1. 配置管理

新增配置项：
```csharp
public int InitialMoveDuration { get; set; } = 18;
public int RandomMoveDurationMin { get; set; } = 1;
public int RandomMoveDurationMax { get; set; } = 3;
```

### 2. 进程信息获取

```csharp
var processes = Process.GetProcesses()
    .Where(p => !string.IsNullOrEmpty(p.MainWindowTitle))
    .OrderBy(p => p.ProcessName)
    .Take(20)
    .ToList();
```

### 3. 设置界面

使用 WPF 动态创建设置窗口：
- Slider 控件用于调整参数
- 实时显示当前值
- 保存后立即生效（动画帧率）或下次移动生效（移动速度）
