# 🎬 新功能：登场动画

## 功能描述

YuGi 桌面宠物现在拥有了精彩的登场动画！

### 启动效果

```
启动程序
    ↓
宠物出现在屏幕左下角
    ↓
缓慢向右移动（18秒）
    ↓
到达屏幕右侧
    ↓
开始随机移动模式
```

## 视觉效果

- **起始位置**: 屏幕左下角（左边距 10px，底部边距 50px）
- **目标位置**: 屏幕右下角（右边距 10px）
- **移动时间**: 约 18 秒
- **移动轨迹**: 水平直线
- **速度变化**: 开始慢 → 中间快 → 结束慢（QuadraticEase）

## 交互说明

### 在移动过程中
- ✅ **可以拖拽**: 左键拖动宠物会停止初始移动
- ✅ **可以右键**: 显示快捷菜单
- ✅ **可以托盘**: 托盘图标正常工作

### 移动完成后
- 自动切换到随机移动模式（如果启用了 AutoMove）
- 宠物会在屏幕上随机走动

## 技术细节

### 实现代码
```csharp
private void StartInitialRightMovement()
{
    isMoving = true;

    double screenWidth = SystemParameters.PrimaryScreenWidth;
    double targetX = screenWidth - this.Width - 10;

    // 创建缓慢的向右移动动画（18秒）
    Duration duration = new Duration(TimeSpan.FromSeconds(18));

    DoubleAnimation moveX = new DoubleAnimation
    {
        To = targetX,
        Duration = duration,
        EasingFunction = new QuadraticEase { EasingMode = EasingMode.EaseInOut }
    };

    moveX.Completed += (s, e) => 
    { 
        isMoving = false;
        if (config.AutoMove && !movementTimer.IsEnabled)
        {
            movementTimer.Start();
        }
    };

    this.BeginAnimation(Window.LeftProperty, moveX);
}
```

### 初始位置设置
```csharp
// 设置窗口初始位置在屏幕左下角
this.Left = 10; // 左边距 10 像素
this.Top = SystemParameters.PrimaryScreenHeight - this.Height - 50; // 底部边距 50 像素
```

## 自定义选项

### 调整移动速度

在 `MainWindow.xaml.cs` 的 `StartInitialRightMovement()` 方法中修改：

```csharp
// 更快（10秒）
Duration duration = new Duration(TimeSpan.FromSeconds(10));

// 默认（18秒）
Duration duration = new Duration(TimeSpan.FromSeconds(18));

// 更慢（30秒）
Duration duration = new Duration(TimeSpan.FromSeconds(30));
```

### 调整起始位置

在 `MainWindow()` 构造函数中修改：

```csharp
// 左下角（默认）
this.Left = 10;
this.Top = SystemParameters.PrimaryScreenHeight - this.Height - 50;

// 左上角
this.Left = 10;
this.Top = 10;

// 屏幕中央
this.Left = (SystemParameters.PrimaryScreenWidth - this.Width) / 2;
this.Top = (SystemParameters.PrimaryScreenHeight - this.Height) / 2;
```

### 调整目标位置

在 `StartInitialRightMovement()` 方法中修改：

```csharp
// 移动到右边（默认）
double targetX = screenWidth - this.Width - 10;

// 移动到屏幕中央
double targetX = (screenWidth - this.Width) / 2;

// 移动到屏幕 3/4 位置
double targetX = screenWidth * 0.75;
```
