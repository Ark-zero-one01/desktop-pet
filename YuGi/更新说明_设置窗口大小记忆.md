# 设置窗口大小记忆功能 - 更新说明

## 🎯 更新内容

### 新增功能
- ✅ **大小记忆**: 设置窗口的大小会被自动保存
- ✅ **自动恢复**: 下次打开设置窗口时恢复上次的大小
- ✅ **配置持久化**: 大小信息保存在配置文件中

## 📝 技术实现

### 1. 配置类扩展

在 `PetConfig.cs` 中添加了两个新配置项：

```csharp
public class PetConfig
{
    // ... 其他配置项 ...
    
    // 设置窗口大小
    public double SettingsWindowWidth { get; set; } = 450;  // 默认宽度
    public double SettingsWindowHeight { get; set; } = 500; // 默认高度
}
```

### 2. 窗口创建时使用配置

```csharp
var settingsWindow = new Window
{
    Title = "YuGi 桌面宠物 - 设置",
    Width = config.SettingsWindowWidth,   // 使用配置的宽度
    Height = config.SettingsWindowHeight, // 使用配置的高度
    MinWidth = 400,
    MinHeight = 450,
    WindowStartupLocation = WindowStartupLocation.CenterScreen,
    ResizeMode = ResizeMode.CanResize
};
```

### 3. 窗口关闭时保存大小

```csharp
// 窗口关闭时保存大小
settingsWindow.Closing += (s, e) =>
{
    config.SettingsWindowWidth = settingsWindow.Width;
    config.SettingsWindowHeight = settingsWindow.Height;
    config.Save();
};
```

## 🎮 使用说明

### 工作流程
```
打开设置窗口
    ↓
调整窗口大小（拖动边缘或角落）
    ↓
关闭设置窗口
    ↓
大小自动保存到配置文件
    ↓
下次打开时自动恢复
```

### 配置文件
位置：`%AppData%\DesktopPet\config.json`

新增的配置项：
```json
{
  "SettingsWindowWidth": 450.0,
  "SettingsWindowHeight": 500.0
}
```

## 💡 使用场景

### 场景一：高分辨率显示器
1. 打开设置窗口
2. 调整到更大的尺寸（如 600x650）
3. 关闭窗口
4. 下次打开自动使用大尺寸

### 场景二：小屏幕设备
1. 打开设置窗口
2. 调整到最小尺寸（400x450）
3. 关闭窗口
4. 下次打开保持紧凑布局

### 场景三：个人偏好
1. 调整到您喜欢的大小
2. 以后每次都使用这个大小
3. 无需重复调整

## 🔧 高级功能

### 重置窗口大小
如果想恢复默认大小，可以：

**方法一：删除配置**
1. 打开 `%AppData%\DesktopPet\config.json`
2. 删除 `SettingsWindowWidth` 和 `SettingsWindowHeight` 行
3. 保存文件
4. 重新打开设置窗口

**方法二：手动编辑**
```json
{
  "SettingsWindowWidth": 450.0,
  "SettingsWindowHeight": 500.0
}
```

### 自定义默认大小
编辑 `PetConfig.cs`：
```csharp
public double SettingsWindowWidth { get; set; } = 600;  // 改为您想要的宽度
public double SettingsWindowHeight { get; set; } = 650; // 改为您想要的高度
```
