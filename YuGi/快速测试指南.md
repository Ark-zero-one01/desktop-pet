# 循环移动快速测试指南

## 🚀 快速测试步骤

### 步骤 1：检查配置文件

1. 按 `Win + R` 打开运行对话框
2. 输入：`%AppData%\DesktopPet`
3. 打开 `config.json` 文件
4. 确认以下内容：

```json
{
  "AutoMove": true,
  "InitialMoveDuration": 18
}
```

如果 `AutoMove` 为 `false`，改为 `true` 并保存。

### 步骤 2：快速测试（5秒循环）

为了快速验证，建议先将移动时间改短：

```json
{
  "AutoMove": true,
  "InitialMoveDuration": 5
}
```

保存后重启程序。

### 步骤 3：观察行为

启动程序后，观察以下内容：

1. **0-5秒**: 宠物从左下角向右移动
2. **5秒时**: 宠物应该从右边离开屏幕
3. **5秒后**: 宠物应该立即从左边重新出现
4. **5-10秒**: 宠物继续向右移动
5. **持续循环**: 重复上述过程

## 🔍 问题排查

### 问题 1：宠物停在右边不动

**可能原因**: `AutoMove` 为 `false`

**解决方案**:
1. 打开配置文件
2. 将 `AutoMove` 改为 `true`
3. 保存并重启程序

### 问题 2：宠物移动很慢

**可能原因**: `InitialMoveDuration` 值太大

**解决方案**:
1. 打开配置文件
2. 将 `InitialMoveDuration` 改为 `5`
3. 保存并重启程序

### 问题 3：宠物根本不移动

**可能原因**: 程序未正确启动

**解决方案**:
1. 检查系统托盘是否有宠物图标
2. 左键点击托盘图标显示宠物
3. 确认宠物窗口可见

## 💡 调试技巧

### 技巧 1：使用短时间测试

```json
{
  "InitialMoveDuration": 3
}
```

3 秒一个循环，更容易观察。

### 技巧 2：观察窗口位置

右键点击宠物 → 查看运行程序，可以看到当前窗口信息。

### 技巧 3：重启程序

每次修改配置后，务必重启程序才能生效。
