  桌面宠物 - 运行说明
═══════════════════════════════════════

【方法 1：使用批处理脚本（推荐）】
----------------------------------
1. 双击运行 "run.bat" 文件
2. 等待编译完成
3. 程序会自动启动


【方法 2：使用 Visual Studio】
----------------------------------
1. 双击打开 "DesktopPet.csproj" 文件
2. 等待 Visual Studio 加载完成
3. 按 F5 键或点击"开始"按钮


【方法 3：使用命令行】
----------------------------------
1. 打开 PowerShell 或 CMD
2. 进入项目目录：
   cd d:\privateweb2\DesktopPet

3. 编译项目：
   dotnet build

4. 运行程序：
   dotnet run


【如果 dotnet 命令无法识别】
----------------------------------
说明你还没有安装 .NET SDK，请：

1. 访问：https://dotnet.microsoft.com/download/dotnet/8.0
2. 下载 "SDK 8.0.x" Windows x64 版本
3. 安装后重启命令行窗口
4. 再次运行上述命令


【操作说明】
----------------------------------
✓ 左键拖拽：移动小猫
✓ 右键菜单：隐藏/退出
✓ 系统托盘：右键图标可显示/隐藏/退出
✓ 双击托盘图标：显示宠物


【常见问题】
----------------------------------
Q: 看不到小猫？
A: 检查 Assets 文件夹中是否有 cat_idle_1.png 到 cat_idle_6.png

Q: 程序无法启动？
A: 确保已安装 .NET 8.0 SDK 或 Visual Studio 2022

Q: 如何退出程序？
A: 右键点击小猫选择"退出"，或右键托盘图标选择"退出"
