# 设置窗口可调整大小 - 更新说明

## 🎯 更新内容

### 设置窗口改进
- ✅ **可调整大小**: 设置窗口现在可以自由调整大小
- ✅ **最小尺寸限制**: 设置了最小宽度和高度，防止窗口过小
- ✅ **保持居中**: 窗口仍然在屏幕中央打开

## 📝 技术实现

### 修改前
```csharp
var settingsWindow = new Window
{
    Title = "YuGi 桌面宠物 - 设置",
    Width = 450,
    Height = 500,
    WindowStartupLocation = WindowStartupLocation.CenterScreen,
    ResizeMode = ResizeMode.NoResize  // 不可调整大小
};
```

### 修改后
```csharp
var settingsWindow = new Window
{
    Title = "YuGi 桌面宠物 - 设置",
    Width = 450,
    Height = 500,
    MinWidth = 400,                    // 最小宽度
    MinHeight = 450,                   // 最小高度
    WindowStartupLocation = WindowStartupLocation.CenterScreen,
    ResizeMode = ResizeMode.CanResize  // 可调整大小
};
```

## 🎮 使用说明

### 调整窗口大小
1. 打开设置窗口（右键 → 设置）
2. 将鼠标移到窗口边缘或角落
3. 当鼠标变成双向箭头时，拖动调整大小
4. 窗口最小尺寸为 400x450 像素

### 窗口操作
- **拖动**: 点击标题栏拖动窗口位置
- **调整宽度**: 拖动左右边缘
- **调整高度**: 拖动上下边缘
- **同时调整**: 拖动四个角落
- **最大化**: 双击标题栏或点击最大化按钮

## 💡 使用场景

### 适合调大窗口
- 高分辨率显示器（2K、4K）
- 需要更清晰地查看设置项
- 喜欢大窗口的用户

### 适合调小窗口
- 小屏幕设备
- 需要同时查看其他窗口
- 喜欢紧凑界面的用户
