## 📋 功能清单

### 基础功能
- ✅ **透明窗口** - 无边框、透明背景、置顶显示
- ✅ **6 帧动画** - 流畅的循环动画播放

- ✅ **右键菜单** - 点击宠物显示快捷菜单
- ✅ **系统托盘** - 最小化到系统托盘
- ✅ **托盘菜单** - 完整的托盘右键菜单
- ✅ **快捷切换** - 左键托盘图标快速显示/隐藏

### 进阶功能
- ✅ **配置保存** - 自动保存设置和位置
- ✅ **位置记忆** - 记住上次关闭时的位置
- ✅ **自动移动开关** - 可以开关自动移动功能
- ✅ **性能优化** - 低 CPU 和内存占用

## ⚙️ 配置说明

### 配置文件位置
```
%AppData%\DesktopPet\config.json
```

实际路径示例：
```
C:\Users\你的用户名\AppData\Roaming\DesktopPet\config.json
```

### 配置文件内容
```json
{
  "WindowLeft": 1720.0,
  "WindowTop": 880.0,
  "AnimationSpeed": 166,
  "AutoMove": true,
  "MoveIntervalMin": 3,
  "MoveIntervalMax": 7
}
```

### 配置项说明
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| WindowLeft | 窗口 X 坐标 | 自动计算 |
| WindowTop | 窗口 Y 坐标 | 自动计算 |
| AnimationSpeed | 动画速度（毫秒/帧） | 166 (6 FPS) |
| AutoMove | 是否自动移动 | true |
| MoveIntervalMin | 最小移动间隔（秒） | 3 |
| MoveIntervalMax | 最大移动间隔（秒） | 7 |

### 手动调整配置

你可以手动编辑配置文件来调整行为：

**加快动画速度**（更流畅但占用更多资源）：
```json
"AnimationSpeed": 83  // 12 FPS
```

**减慢动画速度**（更省资源）：
```json
"AnimationSpeed": 250  // 4 FPS
```

**调整移动频率**（更频繁移动）：
```json
"MoveIntervalMin": 1,
"MoveIntervalMax": 3
```

**禁用自动移动**：
```json
"AutoMove": false
```
