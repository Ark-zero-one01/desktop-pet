  托盘菜单测试步骤
═══════════════════════════════════════

【重要提示】
----------------------------------
请确保：
1. 已关闭旧的程序实例
2. 重新运行 run.bat 或按 F5
3. 使用的是最新编译的版本


【测试步骤】
----------------------------------

步骤 1: 启动程序
   - 双击 run.bat
   - 或在 Visual Studio 中按 F5
   - 小猫应该出现在屏幕上

步骤 2: 找到托盘图标
   - 查看任务栏右下角
   - 如果没看到，点击 "^" 展开隐藏的图标
   - 应该能看到一个应用程序图标

步骤 3: 右键点击托盘图标
   - 右键点击托盘图标（不是小猫）
   - 应该弹出菜单，包含以下选项：
     ☐ 显示宠物
     ☐ 隐藏宠物
     ─────────────
     ☑ 自动移动  ← 这个选项应该有勾选框
     ─────────────
     ☐ 退出

步骤 4: 测试自动移动开关
   - 点击"自动移动"选项
   - 勾选应该消失，小猫停止自动移动
   - 再次点击，勾选出现，小猫恢复移动


【如果看不到"自动移动"选项】
----------------------------------

可能原因 1: 程序未重新编译
   解决方法：
   1. 关闭所有运行中的 DesktopPet 程序
   2. 删除 bin 和 obj 文件夹
   3. 重新运行 run.bat

可能原因 2: 使用了旧的 exe 文件
   解决方法：
   1. 在任务管理器中结束所有 DesktopPet 进程
   2. 确保从项目根目录运行 run.bat
   3. 或在 Visual Studio 中按 F5

可能原因 3: 点击位置不对
   解决方法：
   - 确保右键点击的是托盘图标
   - 不是右键点击小猫本身


【验证编译版本】
----------------------------------

检查编译时间：
1. 打开文件夹：D:\privateweb2\DesktopPet\bin\Debug\net8.0-windows\
2. 查看 DesktopPet.exe 的修改时间
3. 应该是最近几分钟内的时间

如果不是，说明程序没有重新编译。


【手动清理重编译】
----------------------------------

在项目目录执行：
1. 删除 bin 文件夹
2. 删除 obj 文件夹
3. 运行：dotnet clean
4. 运行：dotnet build
5. 运行：dotnet run
